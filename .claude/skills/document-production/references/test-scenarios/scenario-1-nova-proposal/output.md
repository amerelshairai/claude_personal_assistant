## 1. Overview
Nova Home Goods is an online home-goods store seeing strong order volume but
losing a meaningful share of potential sales to abandoned checkouts — shoppers
who start an order but don't complete it.

## 2. Recommended Solution
An automated follow-up system that checks in on incomplete orders: if a checkout
isn't finished, we send a friendly reminder after a short delay, and — if that
doesn't lead to a completed order — a follow-up message with a small incentive to
come back and finish. Every incentive stays within a cap you set, so there's
never a surprise on cost.

## 3. What's Included
- Automated checkout-status check
- Delayed reminder message (WhatsApp)
- Capped-incentive follow-up message
- Outcome tracking, so we can see what's working over time
