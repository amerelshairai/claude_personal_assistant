# projects/

One directory per client or engagement. Suggested layout:

```
projects/<client>/
├── source/           # material Amer supplied: docs, notes, screenshots
├── intelligence/     # Client Intelligence Packages (dated)
├── analysis/         # cost, ROI, comparison — internal only
├── architecture/     # automation designs, workflow JSON, diagrams
├── deliverables/     # client-facing output (Level 2 — review before sending)
└── plan.md           # project plan from the project-planning skill
```

`deliverables/` is client-facing. Nothing with internal cost or margin goes there.
